# Premarket Alert (日本株 寄り付き・トレンド監視システム)

毎朝、東証の全上場銘柄から強いトレンドを持つ銘柄を抽出し、寄り付き直後に「ギャップアップし、かつ出来高が急増している」銘柄をSlackに自動通知するシステムです。

## ⚙️ システムの流れ（完全自動）

1. **07:55 - Macが自動起床**
   - スリープ状態から自動的に復帰します。
2. **08:00 - ウォッチリストの自動更新** (`update_watchlist.py`)
   - 東証の全銘柄データを取得し、厳しい条件（流動性・トレンド・高値圏）でスクリーニング。
   - 合格した優良銘柄だけを `watchlist.txt` に書き出します。
3. **09:25 - 寄り付き直後の急騰検知** (`premarket_alert.py`)
   - `watchlist.txt` の銘柄群に対し、当日の寄り付き状況を確認。
   - ギャップアップ＆出来高急増などの条件を満たした銘柄をSlackへ通知します。

---

## 🔍 売買手法とフィルター条件

### 手法の考え方
**「中長期で上昇トレンドにある流動性の高い銘柄が、寄り付き直後に出来高を伴って上放れた瞬間」を捉えるモメンタム(順張り)戦略**です。

1. **8:00 の事前スクリーニング**:「上がりやすい土台がある銘柄」に絞ります(日足ベース)。
2. **9:25 の当日判定**:その中から「今日まさに資金が流入している銘柄」を検出します(分足ベース)。

判定に使うデータはすべて **株価と出来高のみ**(テクニカル)です。

> [!IMPORTANT]
> **ファンダメンタル条件は現在1つも実装していません。** 業績・PER/PBR・時価総額・決算日などは見ていません。
> 時価総額のフィルターは、全銘柄分を毎日取得する負荷が高いため実装を見送り、代わりに「売買代金5億円以上・株価250円以上」で小型株や低位株を除外しています。

---

### ステップ1:ウォッチリスト抽出(8:00 / `update_watchlist.py`)
対象は東証の全上場銘柄のうち「内国株式」です(ETF・REIT・ETN などは除外)。前営業日までの日足(過去6か月)で判定し、**以下をすべて満たす銘柄**を `watchlist.txt` に書き出します。

| 分類 | 条件 | しきい値 | 狙い |
|---|---|---|---|
| 流動性 | 25日平均売買代金(終値×出来高) | **5億円以上** | 板が薄く、少額の買いで値が跳ねる銘柄を除外 |
| 株価水準 | 直近終値 | **250円以上** | 超低位株(ボロ株)を除外 |
| トレンド | (終値 > 25日移動平均 **かつ** 25日線が上向き)**または**(終値 > 75日移動平均 **かつ** 75日線が上向き) | — | 下降トレンド中の一時的な反発(ダマシ)を除外 |
| 高値圏 | 直近終値が、過去60日の最高終値から何%下にあるか | **10%以内** | レンジ上限(抵抗線)付近にあり、ブレイクを狙える位置 |

- 移動平均の「上向き」は、**当日値が前日値より大きいか**だけで判定しています。
- 75日線を計算するため、上場から80営業日未満の銘柄は対象外になります。

---

### ステップ2:寄り付き直後のアラート判定(9:25 / `premarket_alert.py`)
ウォッチリストの各銘柄について、当日の1分足と過去1か月の日足で判定します。**以下をすべて満たす銘柄**を Slack に通知します。

| # | 分類 | 条件 | 既定値 | 環境変数 | 狙い |
|---|---|---|---|---|---|
| 1 | 前日の過熱 | 前日の騰落率 | **+5%未満** | `PREV_DAY_MAX_RETURN` | 前日に急騰した銘柄の翌日の利確売りを避ける |
| 2 | 前日の過熱 | 前日出来高 ÷ その前5日の平均出来高(前日自身は含めない) | **2倍未満** | `PREV_DAY_MAX_VOL_RATIO` | 同上(材料出尽くしを避ける) |
| 3 | ギャップ | 現在値の前日終値比 | **+3%〜+10%** | `GAP_THRESHOLD` / `MAX_GAP_THRESHOLD` | 上放れは必須、ただしストップ高付近の上がりすぎは除外 |
| 4 | 出来高ペース | 当日出来高 ÷ 過去5日平均出来高 ≥ 目標倍率 × 経過時間の割合 | 1日で**1.5倍**になるペース | `TARGET_DAILY_RATIO` | 資金流入の強さ(相対出来高) |
| 5 | ローソク足 | 現在値 ≥ 当日の始値(陽線) | — | — | 寄り天(高く始まってすぐ売られる)を除外 |
| 6 | 高値維持 | 当日高値からの下落率 | **1%以内** | `CLOSE_TO_HIGH_THRESHOLD` | 上ヒゲをつけて失速した銘柄を除外 |

**出来高ペースの計算方法(条件4)**
- 東証の立会時間 **330分**(前場150分+後場180分)のうち、何分が経過したかで按分します。昼休み中は前場終了時点として扱います。
- 例:9:25 なら経過25分なので、要求ラインは `1.5 × 25 / 330 ≒ 11.4%`(5日平均出来高に対する割合)です。

### 使っているテクニカル指標の一覧

| 指標 | どこで使うか | 用途 |
|---|---|---|
| 単純移動平均(SMA 25日・75日)とその傾き | 抽出 | 中期トレンドの方向 |
| 60日高値との距離 | 抽出 | 高値圏・ブレイク候補の判定 |
| 平均売買代金(25日) | 抽出 | 流動性 |
| ギャップ率(前日終値比) | 判定 | 当日の上放れ |
| 相対出来高(RVOL・時間按分) | 判定 | 資金流入の強さ |
| 始値との比較(陽線/陰線) | 判定 | 寄り付き後の値動きの方向 |
| 当日高値からの下落率 | 判定 | 勢いが続いているか |
| 前日の騰落率・前日の出来高倍率 | 判定 | 過熱・材料出尽くしの除外 |

---

### 既知の制約・注意点
- **データの遅延**:Yahoo Finance の日本株データは約20分遅れます。9:25 に実行しても、実際に見ているのは 9:05 前後の値動きです。一方、出来高の要求ラインは実行時刻(9:25)で計算するため、条件4は実質的に厳しめになります。
- **yfinance は非公式 API**:仕様変更や取得制限で、データが取れなくなることがあります。
- **「高値」は終値ベース**:ステップ1の60日高値は、日中の高値ではなく終値の最高値です。
- **傾きの判定が粗い**:移動平均の上向きは前日比だけで見ているため、横ばい付近ではノイズで判定が入れ替わります。
- **売買判断は自己責任で**:このシステムは通知だけを行い、売買の推奨ではありません。

### バックテスト(`backtest.py`)
指定した「銘柄と日付」について、次のルールで成績を検証します。
- **エントリー**:9:30 の始値で買い
- **決済A**:10分後に決済
- **決済B**:1時間以内の最大上昇幅を計測(潜在的な利益の確認用)
- **損切り**:買値から **-3%** に達したら損切り

> [!WARNING]
> 現在の `backtest.py` は、**検証する銘柄を手動で指定**する方式です。`premarket_alert.py` の条件で通知が出た銘柄を自動で選ぶ仕組みにはなっていません。そのため、アラートの精度そのものを測る検証にはまだなっていません。

*(※ しきい値は環境変数、または `premarket_alert.py` / `update_watchlist.py` の上部の定数で変更できます)*

## 🚀 セットアップと手動コマンド

既に設定は完了していますが、設定を変更したり手動でテストしたい場合は以下のコマンドを利用してください。

### 1. ウォッチリスト更新の手動実行
銘柄リストの抽出を今すぐ手動で実行したい場合はこちら。
```bash
cd ~/premarket_alert
./run_update.sh
```
*(※ 100銘柄ずつ2秒間隔で取得するため、完了まで5分〜10分程度かかります。進行状況は画面には出ませんが `update.log` に出力されます)*

### 2. アラート通知の「通常テスト」
設定している実際の条件のまま、今の時間で判定させたい場合はこちら。
```bash
cd ~/premarket_alert
./run.sh
```
*(※ 条件を満たす強い銘柄がなければSlackには何も通知されません。実行結果は `alert.log` を確認してください)*

### 3. アラート通知の「強制テスト」
条件を満たす銘柄があるかどうかにかかわらず、必ずSlackへ通知を飛ばして連携を確認したい場合はこちら。
(※条件を -1% / 要求出来高 0倍 に緩めて強制的に発火させます)
```bash
cd ~/premarket_alert
GAP_THRESHOLD=-1 TARGET_DAILY_RATIO=0 CLOSE_TO_HIGH_THRESHOLD=1.0 ./run.sh
```
*(※ 東証が開いている平日 9:00〜15:30 以外に実行しても当日データがないため通知されません)*

### 4. ログファイルではなく、画面で結果を見ながら直接実行
`run.sh` を使うと結果が `alert.log` に保存されて画面には出ません。エラー文や取得状況をターミナルの画面で直接確認したい場合は、以下のように環境変数と仮想環境のPythonを指定して直接実行します。
```bash
cd ~/premarket_alert
set -a; source secrets.env; set +a
/Users/msngkntr/.venv/bin/python premarket_alert.py
```

### Macの自動起床時間の変更
現在は `07:55` に設定されています。変更したい場合は以下のコマンドを実行します。
```bash
sudo pmset repeat wakeorpoweron MTWRF 07:55:00
```
設定状況の確認: `pmset -g sched`

### 自動実行(launchd)の登録・解除
設定ファイルは `com.msngkntr.update_watchlist.plist` および `com.msngkntr.premarket_alert.plist` です。

**登録を解除して自動実行を止める:**
```bash
launchctl unload ~/Library/LaunchAgents/com.msngkntr.update_watchlist.plist
launchctl unload ~/Library/LaunchAgents/com.msngkntr.premarket_alert.plist
```

**再度登録する:**
```bash
launchctl load ~/Library/LaunchAgents/com.msngkntr.update_watchlist.plist
launchctl load ~/Library/LaunchAgents/com.msngkntr.premarket_alert.plist
```
*(※ `launchctl list | grep premarket` で登録状況を確認できます)*

## 📁 構成ファイル一覧
- `premarket_alert.py` : 9:25に動くアラート判定スクリプト
- `update_watchlist.py` : 8:00に動く銘柄リスト更新スクリプト
- `backtest.py` : 9:30エントリーのデイトレード・バックテスト
- `run.sh` / `run_update.sh` : それぞれを実行するためのシェルスクリプト
- `secrets.env` : Slack Webhook URL が記載された機密ファイル
- `watchlist.txt` : 自動更新される監視対象の銘柄一覧
- `*.plist` : Macのlaunchdにスケジュールを登録するための設定ファイル
- `alert.log` / `update.log` : 実行結果のログファイル
